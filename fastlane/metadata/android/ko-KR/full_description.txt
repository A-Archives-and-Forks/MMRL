MMRL은 자신만의 모듈 저장소를 관리할 수 있도록 도와주는 Android 앱입니다.

기능:
- 모듈 저장소 관리
- 여러 저장소 지원
- Magisk 및 KernelSU 지원
- Jetpack Compose & Material Design 3

https://github.com/DerGoogler/MMRL

<i>Magisk Module Repo Loader</i> (MMRL)를 사용하면 간단한 UI로 사용자 지정 Magisk 저장소를 불러올 수 있습니다. <a href="https://github.com/Magisk-Modules-Alt-Repo">Magisk Modules Alternative Repository</a>가 기본으로 구성되어 있으며, 사용자 지정 저장소를 추가할 수 있습니다.</p>

<b>어떤 root 관리자가 MMRL을 지원하나요?</b></p>

* Magisk
* KernelSU
* APatch

<b>MMRL은 어떤 기능을 제공하나요?</b>

* 사용자 친화적인 UI
* 구성 가능한 모듈 페이지 (ModConf)
* 모든 경로 사용자 지정 (root가 다른 경로를 사용하는 경우 "/data/adb/modules" 등)
* ModConf Playground
* 설치된 모듈 및 업데이트 가능한 모듈 보기
* 커버, 스크린샷, 검증, 종속성 등 추가 (저장소 기반)
* 검색 기능
* 최대 5개의 저장소 추가

이 앱은 root 권한이 필요하며, root 없이는 작동하지 않습니다!

참고: 다른 모듈을 설치하려면 MMRL-CLI가 필요합니다
